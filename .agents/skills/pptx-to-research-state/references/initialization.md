# Initialize a research knowledge base

Use only when the user asks to initialize a project from named PPTX files. Resolve the project and inputs; preserve existing user content. For an existing knowledge base, switch to incremental-update.md instead of regenerating its notes.

- Before extraction, use the available maintain-research-state `scripts/initialize_project.py --root <project-root> --date YYYY-MM-DD --layout-only` to create the standard directory frame and its controls without touching scientific notes. For an existing AGENTS.md, preserve its rules and append only a missing mandatory directory-policy entry; already linked policies are not duplicated. The shared layout preset and policy belong to that skill; do not duplicate their definitions. If the helper is unavailable in another environment, resolve the target project's actual layout contract before creating files; do not emit an AGENTS.md with mandatory missing layout paths.
- Preserve input PPTX files in `sources/presentations/` when importing them into the project. Extract and visually verify evidence using [pptx-evidence.md](pptx-evidence.md), with intermediate work under `.work/pptx/<input-key>/`.
- Create missing CURRENT_STATE.md, RESEARCH_QUESTIONS.md and PROJECT_STORY.md from the templates in `../assets/`. Populate from this project's evidence, replacing placeholders and removing empty non-story sections. Retain all six mandatory story sections; handle missing information through story-workflow.md rather than deleting a required section. Never borrow another project's scientific content.
- Use [incremental-update.md](incremental-update.md) for evidence separation, update dependencies and final checks, and [story-workflow.md](story-workflow.md) for the first story layer.
- Create AGENTS.md from `../assets/AGENTS.template.md` only if missing. Preserve existing instructions and add only an actually missing requirement. Resolve skill routes from available project files or the active catalog; never emit mandatory broken paths or copy/install dependencies without authorization.
- Exactly four files form the main research layer: AGENTS.md and the three research notes. Initialization also supplies the shared directory frame and layout controls. Do not create SOL files, extra scoring cards or narrative subdirectories.
- Identify the initial stories as target narratives with their current evidence limits. Complete the requested initialization without adding a follow-up menu.

For structure, use the available maintain-research-state skill and its schema, selecting one validation level for the completed batch. If no structural skill exists in a different target project, preserve its established ID conventions; use the compact template contract and manually verify the newly created entries and links once.
