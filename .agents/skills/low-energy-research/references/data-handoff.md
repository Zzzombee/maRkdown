# 作图数据导出

仅在确定汇报信息点与展示方案之后执行本节。表格整理是下游步骤，不能作为整次进展汇报请求的终点。

默认时间过程准备给 OriginPro 2026，分组/配对比较按真实实验设计准备给 Prism 9.5.0；不从文件数推定生物学重复数。每页对应一个已选用途，一行列名带单位，完整数值连续排列。共用 X 仅用于时间精确一致的系列。仅有图片先找数值源，不将估读值伪装成精确数据。

面向用户默认交付 XLSX。多个指标放在同一工作簿的不同工作表中，工作表按指标命名；不要把 TSV/CSV 作为唯一入口，除非用户明确要求文本格式。

从会话依赖工具获得 Python、Node、node_modules 的绝对路径。所有命令由 Agent 执行，用户不需要操作终端。

下文 WORK 固定指 `.work/<任务>/`，OUTPUT.xlsx 位于 `outputs/reports/<YYYYMMDD_任务>/`。来源及必要交付说明随工作簿保留；不得为导出数据创建另一个顶层 output/。共享依赖 junction 不计入项目数据，不对其目标执行目录清理。

1. 只读检查实际工作表和列名。选用已匹配 recipe 或生成同结构小型 JSON；用 `series_values` 数组显式选系列，不提供则保留全部。多个字段是记录唯一键时，先确认真实系列身份，不用平均消除重复。
2. 运行 `python prepare_plot_data.py --input SOURCE.xlsx --recipe RECIPE.json --output WORK/data.json`。
3. 将 `export_plot_workbook.mjs` 复制到会话工作目录。按 spreadsheet skill 连接工作目录 node_modules，并记录创建操作。
4. `node export_plot_workbook.mjs WORK/data.json OUTPUT.xlsx WORK/previews`。
5. 查看三张首屏 PNG（仅内部验证，不额外交付用户），并用只读库将最终文件与 JSON、源表逐项比较，验证全部行和浮点数在 1e-12 相对/绝对容差内一致。此容差只用于序列化校验，时间共用条件仍是精确相同。
6. 在简短旁文件中记录来源、是否保留全部系列/时间点、无平滑/插值/新增统计，以及影响使用的未解决 QC。不要复制整个日志。

配置中的 metrics 决定输出页，仅选当前目的需要的指标。不同时间序列自动输出成独立 XY 配对列并用空白补齐尾部；空白是无数据，不是零。重复时间键、未缓存公式、非有限数字、缺少标识等将明确报错；先核对数据，不能静默删行通过。

程序不会重新计算 G、b、Vnull 或噪声，也不会推断独立样本数、显著性或机制。运行记录保留配置、源文件 SHA256、各单元格源行映射和是否共用 X，供 Agent 核验。
