# 项目故事与主张边界

本文件承接 2026-09-21 从 AGENTS.md 迁出的既有政策，并于 2026-10-12 按用户要求冻结六节故事结构与正式论文式摘要规则；本次未新增或重新核验科研主张。涉及故事、创新性、机制、功能或工程能力主张时读取。当前事实仍以 CURRENT_STATE.md 为准，发现冲突时按 AGENTS.md 处理；更新相关主张边界时同步维护此处，不能把本文件当作新增实验证据。

### 定位

`PROJECT_STORY.md` 是项目的**目标论文叙事层**。Story 指一种接近论文标题和摘要的完整叙事：用确定陈述说明课题的重要性、核心发现、相对于 prior art 的新颖性、研究价值，以及本项目形成该发现的独特基础。它服务于研究取舍、实验优先级和论文定位。

每个 story 的小标题直接承担标题式核心主张；不再另设与小标题重复的“核心命题”或“标题式陈述”。摘要式故事按体系已经完成并正式发表的完整论文写作，证据链尚不充足的环节按用户所选故事路线的成功结果补齐，以确定的结果性语言讲清问题、方法或原理、发现和价值。不使用“预期”“拟”“计划”“如果成功”“有望”“尚待验证”等措辞，不在摘要中插入证据缺口或核验警示。该规则适用于目标故事摘要，不适用于实际论文投稿、真实结果汇报、CURRENT_STATE、RQ 或 SOL 的事实陈述。

目标叙事身份在文档级说明一次；当前支持程度、证据边界、阴性或矛盾结果和论文成立条件集中在第六节，以 `CURRENT_STATE.md` 的证据等级为准。成功结果补齐仅用于所选故事的定性论证关系，不补造数值、样本量、统计显著性、关键实验参数、引用或未指定的机制与疾病路线，也不自动建立 CON。新颖性与外部文献真实性仍须独立核验。

### 固定六节与内容职责

以下六节为故事的必备结构，名称和顺序固定；不得仅凭当轮任务措辞省略或合并。用户明确指定独立故事文件时也沿用该结构。允许在节内使用必要的分组标题，不额外增加重复的主节。

1. **摘要式故事。** 用 2–3 个紧凑段落连贯叙述“重要问题—方法或原理—完整成功结果—研究价值”，遵循上述正式论文式摘要规则。避免逐图转述和无必要的样本、参数细节。
2. **领域背景与未解决问题。** 合并研究重要性与领域研究缺口：说明问题如何产生、已有研究如何回应、仍未回答什么及其原因。采用“已有进展—解答范围—剩余问题”的综述逻辑；对体系、测量、设计或解释范围的判断配对应文献。本节讨论领域研究的解答不足，不写本项目尚缺的实验、对照或结论。
3. **文献定位与创新点。** 必须分别列出“已有研究覆盖的能力”和“本研究的创新贡献”。前者每条为能力、已覆盖范围和直接文献；后者每条为加粗贡献短句及相对已有研究新增的具体关系、原理或能力。区分核心创新、依赖核心创新的功能贡献与应用价值，不机械凑固定数量。检索范围及核验状态用简短说明收束，未核验的背景不能作为已确立的新颖性证据。
4. **论文论证链。** 以有序短条目展示结果如何共同支撑故事，每条包含“要建立的命题—它在论文中的作用”。保持完整故事线，不复制提取台账，不逐图罗列坐标、比例尺、全部参数和样本标签，也不逐条重复证据缺口。
5. **本项目的独特基础。** 用少量条目说明与故事直接相关的材料基础、既有观察和技术能力，链接对应项目条目。区分已发表材料基础、本项目证据与实施能力；不重复第四节结果链，不把设备或实施条件写成科学创新。
6. **当前证据与成立条件。** 按核心命题对应写明“当前支持到哪里—尚需建立什么决定性连接”，链接实际 OBS/CON/HYP/RQ。保留阴性、矛盾和替代解释，仅列影响故事成立的关键条件，详细实验设计链接 RQ 或 SOL。样本数冲突、图注用词或来源核对细节可放在本节末尾的折叠备注中，仍保留可追溯信息。

每段和每条只承担其所在分节的任务；重复的研究价值、材料基础和证据限制各归一个主要位置。文献定位中的短条目负责贡献边界，领域背景中的综述负责解释问题来源与已有研究不足。完整书目尽量复用文件内统一参考文献区，不在每个故事里复制长书目或核验过程。

### 操作说明

1. 形成或修改故事前，先核对 `CURRENT_STATE.md` 和 `RESEARCH_QUESTIONS.md`。项目内事实、结论、假设和问题必须使用对应的 Obsidian wikilink，不能在 `PROJECT_STORY.md` 中另建一套事实版本。
2. 每个候选故事使用上述固定六节，默认在 PROJECT_STORY.md 中新增或更新；除非用户明确要求，不新增评分卡、故事子文件或多层目录，也不因新增候选版本自动替换其他故事或改变优先级。模板为 `.agents/skills/pptx-to-research-state/assets/PROJECT_STORY.template.md`，分节职责以本文件为准。
3. 所有候选故事都必须体现本项目区别于普通吸光颗粒的共同材料基础：已发表体系中的石墨烯自发膜插入能力，以及 CON-003 所示的 PC12 膜区域数天关联。实际证据边界集中写入第六节：前者不能证明脑内构型，后者不能区分膜表面吸附、部分嵌入或真正跨膜，也不能证明长期功能稳定；不在摘要和论证链中重复插入这些限制。
4. 获得新实验结果时，先更新 `CURRENT_STATE.md`；如果结果改变故事可行性、主次关系或证据缺口，再同步更新 `PROJECT_STORY.md`。研究问题或优先级改变时，先更新 `RESEARCH_QUESTIONS.md`，再调整故事。
5. 新文献改变 prior art、竞争格局或新颖性判断时，先执行 `literature-source-gate` 再更新 `PROJECT_STORY.md`；外部文献不得改变项目自身 `OBS` 或 `CON` 的证据等级。
6. Story 的文献定位必须区分已被 prior art 覆盖的能力与剩余材料—体系—刺激—readout 组合差异；受限来源、间接证据、检索范围和“尚未找到”的表述均按 `literature-source-gate` 处理。
7. 候选故事的排序应由当前证据贴合度和关键实验的判别力决定。优先推进能同时区分竞争解释、改变故事成立与否的实验，而不是仅增加叙事所需的描述性数据。

### 限制

- 摘要式故事必须用确定语言表达完整成功结果；该语言不自动成为 `CON`。第六节必须链接 `CURRENT_STATE.md` 中实际成立的 `OBS`、`CON` 和 `HYP`，明确区分成功叙事与真实证据。
- “首次”“唯一”“前所未有”及同义表述只有在 `literature-source-gate` 要求的系统性、范围明确的 prior-art 检索通过后才能使用。
- 近期先例已经覆盖可注射材料与活体皮层长期光调控（Chen et al., 2024，DOI: 10.1038/s41467-023-44635-8）、野生型小鼠非遗传深脑调控（Jin et al., 2025，DOI: 10.1126/sciadv.adt4771）、graphene actuator、宽 spike latency 与数周重复训练（Molokanova et al., 2025，DOI: 10.1038/s41467-025-62637-6），以及活细胞中的 graphene 自发跨膜（Zhou et al., 2024，DOI: 10.1021/acs.nanolett.4c03255）。这些元素不能单独作为本项目新颖性。当前可保留的组合差异是：**游离石墨烯在完整脑组织中自发形成跨膜或持续膜耦合界面，并证明该界面的纵向功能及其对光诱导神经响应的因果贡献。**
- 在实际证据陈述中，当前不得宣称已证明脑内跨膜构型、膜耦合导致延迟响应、长期可重复光调控、特定光电/光热/光化学机制、学习记忆增强或疾病改善。摘要式故事对用户已选方向按完整成功结果叙述，第六节保留这些未建立状态，不因此提高证据等级。
- 当前实际体系需要局部注射、光递送和硅探针记录；在真实证据陈述中，缺少对应系统证据时不得称为“无线”“微创”“无创”或具有临床可用性。用户明确选入故事的工程目标可按摘要规则叙述，第六节须界定其尚未建立的系统证据，不自行添加临床或其他工程目标。
- “结构更简单”“无需预制基底”“可能原位形成界面”可以作为设计特征或待验证工程优势，但不能自动推出更安全、更可控、更适配组织几何或批间一致性更高。
